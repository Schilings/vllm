## 补充：CanonicalKVCache* 三 dataclass 用法讲解
- `CanonicalKVCaches`（kv_offload/base.py:401-462）是 connector worker → offload worker 的唯一数据接口。
- `tensors` = 按 `untyped_storage().data_ptr()` 去重后的物理 GPU 张量列表；`tensor` 形状 `(num_blocks, page_bytes)` int8 视图。
- `group_data_refs` = 每个 KV cache group 的层→物理张量映射（`CanonicalKVCacheRef{tensor_idx, page_size_bytes}`）。
- 构造点：`register_kv_caches`（per-layer）/ `register_cross_layers_kv_cache`（跨层 packed，1 tensor 1 ref，worker.py:295）。注意 base.py:424-437 docstring 示例值（32 个 ref 各 64KB）与跨层路径实际（1 ref、page=2MB）不完全一致，仅为示意。
- 消费点：`CPUOffloadingWorker.__init__` 遍历 tensors 分配 CPU buffer；`transfer_async`（gpu_worker.py:241）按 group_data_refs 逐层算 DMA 字节指针，copy size = `data_ref.page_size_bytes`。
